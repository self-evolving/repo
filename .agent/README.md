# Sepo

This folder is Sepo's home inside the repository: the agent runtime, prompts, skills, and documentation that make this a **self-evolving repository**.

- **Documentation** — [`.agent/docs`](docs/index.md), published at [docs.sepo.sh](https://docs.sepo.sh).
